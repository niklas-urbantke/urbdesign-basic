Baukasten und Style-Guide

Ein token-basiertes Design-System im Thema „Aero Plasma“: echtes Glas mit Unschärfe, eine feine Schattenkante unten, ein weicher Glanz und ein farbiger Hintergrund, der durch alles hindurchscheint. Azure ist der Akzent, Indigo der Partner im Verlauf, Amber und Jade ergänzen die Klaviatur.

Light & Dark Semantische Tokens Ohne Framework Ohne Aufbauschritt

04 Glas

Das Fundament des Themas. Eine halbtransparente Fläche rechnet den Hintergrund unscharf und hebt seine Sättigung an. Dazu kommen eine helle Schattenkante unten, ein weicher Glanz von oben und eine feine Körnung. Das gestreifte Muster hinter den Kacheln ist mit Absicht laut: nur daran ist die Unschärfe wirklich abzulesen.

.glass Die Grundfläche. Mittlere Unschärfe, mittlerer Tint, feine Schattenkante unten.
.glass--strong Dichter und stärker unscharf. Für Dialoge, Menüs und alles, was lesbar bleiben muss.
.glass--sunken Eingelassen statt aufgelegt. Der Lichtrand sitzt unten, die Fläche wirkt vertieft.
.glass--glow Mit farbigem Schein dahinter. Markiert die aktive Fläche im Bild.

Woraus besteht eine Glasfläche?

Aus vier Lagen: der halbtransparenten Grundfläche mit Unschärfe, der inneren Schattenkante unten, dem weichen Glanz von oben und der feinen Körnung darüber.

Warum braucht die Seite einen bunten Hintergrund?

Unschärfe kann nur zeigen, was hinter ihr liegt. Vor einer einfarbigen Wand sieht Glas aus wie eine graue Fläche.

Wie kommt das dunkle Design zustande?

Nur die semantische Ebene wird ausgetauscht. Kein Komponentencode kennt eine Farbe, deshalb wirkt der Wechsel überall gleichzeitig.

13 Dialog und Tooltip

Der Dialog ist die dichteste Glasfläche des Systems, damit sein Text auch über bewegtem Grund lesbar bleibt. Er liegt auf der Ebene --z-modal, der abdunkelnde Grund dahinter heißt modal__backdrop. Hier steht er zur Ansicht im Fluss, gerahmt von modal-demo.

Dienst wirklich entfernen?

Die Daten des Dienstes bleiben im Datenordner erhalten. Die Verbindung zum Arbeitsbereich wird gelöst und muss neu eingerichtet werden.

14 Icons

Ein Strichsatz in fünf Darstellungsarten. Jedes Symbol im Sprite nimmt Strich und Füllung von außen entgegen, deshalb wirken Tönung, Duotone und Verlauf ohne eigene Zeichnung. Die vollständige Übersicht mit Suche steht in icons.html.

Größen

xs sm Standard lg xl

1. Einfarbig

Der Strich folgt der Textfarbe. Das ist der Normalfall in Bedienelementen.

search settings user calendar clock link terminal git-branch

2. Bunt: Tönung aus der Palette

Eine Klasse setzt den Strich auf einen Markenton oder eine Statusfarbe.

azure indigo amber jade rose slate accent success warning danger info

3. Duotone

Zusätzlich eine zarte Füllung der geschlossenen Flächen, im selben Ton.

cloud folder bookmark shield heart box

4. Verlaufsstrich

Der Strich nimmt einen Verlauf aus dem Sprite an. Das ist die Aero-Fassung und wirkt am besten in größeren Größen.

grad-azure grad-indigo grad-amber grad-jade grad-rose grad-accent grad-warm grad-cool

5. Kachel

Das Symbol sitzt auf einer quadratischen Glaskachel mit Verlauf und Farbverlauf. Die Vista-Optik in Reinform, gedacht für Startseiten und Kategorien.

azure indigo amber jade rose slate
