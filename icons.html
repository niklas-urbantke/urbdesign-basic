Icon-Baukasten

Linien-Icons im Aero-Plasma-Stil, 24×24, farbfähig. Der Strich hängt an --icon-stroke, die Fläche an --icon-fill. Damit lässt sich dasselbe Sprite einfarbig, getönt, als Duotone, mit Verlaufsstrich oder in einer Glaskachel zeigen. Jedes Symbol bringt seinen Markenton als data-tone mit. Ein Klick kopiert das passende Schnipsel.

Icons konnten nicht geladen werden

Diese Seite holt icons.svg per Skript. Beim direkten Öffnen als Datei blockieren das viele Browser. Bitte über einen lokalen Server aufrufen, zum Beispiel python3 -m http.server im Projektordner.
